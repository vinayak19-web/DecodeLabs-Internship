# 🎯 Number Guessing Game

A console-based **Number Guessing Game developed in Java** as part of my **Java Programming Internship at Decode Labs**.

## 📌 About the Project

This program generates a random number between **1 and 100** and asks the user to guess the number. After each guess, the program provides feedback to help the user find the correct number.

- If the guess is higher than the secret number → **Too High**
- If the guess is lower than the secret number → **Too Low**
- If the guess is correct → **Correct!**

The game continues until the user correctly guesses the randomly generated number. The program also keeps track of the number of attempts made by the user.

## ⚙️ How It Works

1. The program generates a random number between 1 and 100.
2. The user is asked to enter a guess.
3. The program compares the guess with the secret number.
4. If the guess is too high or too low, appropriate feedback is displayed.
5. The user continues guessing until the correct number is found.
6. The total number of attempts is displayed after the correct guess.

## Student Grade Calculator (Java)

### 📌 Project Description
The Student Grade Calculator is a simple Java application that calculates a student's total marks, average percentage, and grade based on marks obtained in multiple subjects.

This project demonstrates basic Java programming concepts such as variables, loops, arithmetic operations, conditional statements, and user input.

### 🎯 Features
- Accepts marks for multiple subjects (out of 100).
- Calculates the total marks obtained.
- Calculates the average percentage.
- Assigns a grade based on the percentage.
- Displays the final result clearly.

### 🛠️ Technologies Used
- **Programming Language:** Java
- **Input Handling:** Scanner Class
- **Concepts:** Variables, Loops, Arithmetic Operations, Conditional Statements
